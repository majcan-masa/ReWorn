# ReWorn – Manj nakupovanja, več izmenjevanja 



## Uvod

Hitra moda je eden največjih onesnaževalcev na svetu, v omarah pa mnogi hranimo oblačila, ki jih ne nosimo več. ReWorn je mobilna aplikacija, ki rešuje oba problema hkrati: omogoča izmenjavo oblačil med mladimi, brez denarja in brez nepotrebnega nakupovanja novega.

## Opis aplikacije

ReWorn je mobilna aplikacija, namenjena izmenjavi oblačil med mladimi. Uporabnik naloži slike oblačil, ki bi jih rad zamenjal. Nato lahko brska po kosih drugih uporabnikov in predlaga zamenjavo: svoj kos za njihov kos.

**Ciljna skupina:** študentje oziroma mladi (18–27 let), ki si želijo prenoviti garderobo brez dodatnih stroškov in so naklonjeni trajnostni modi.

## Vizija

Želimo ustvariti skupnost, v kateri oblačila krožijo naprej namesto na odpad. Z enostavno uporabo (swipanje, kot pri znanih aplikacijah za spoznavanje) želimo izmenjavo narediti hitro, zabavno in dostopno vsakomur. Vsaka izmenjava pomeni manj odpadkov, manj porabe virov in nov kos v omari brez stroška.

## Funkcionalnosti

- Registracija in prijava uporabnika
- Urejanje profila in pregled svojih oblačil
- Objava kosov (ime, opis, slike, kategorija)
- Urejanje kosov (sprememba podatkov ali izbris)
- Pregled svoje »omare«
- Všečkanje kosov s potegom (swipe)
- Komunikacija z ostalimi uporabniki

## Struktura aplikacije

Aplikacija je sestavljena iz petih glavnih zaslonov:

| Zaslon | Opis |
|--------|------|
| **Domov** | Swipanje oblačil, iskanje in filtriranje po kategorijah |
| **Razišči** | Brskanje po vseh oblačilih |
| **Dodaj** | Obrazec za objavo oblačila (ime, velikost, stanje, lokacija, opis, fotografije) |
| **Sporočila** | Pogovori z drugimi uporabniki in dogovarjanje o izmenjavi |
| **Profil** | Podatki uporabnika (lokacija, Instagram) in njegove objave |


## Predvidene tehnologije

- **Flutter** – razvoj mobilne aplikacije
- **PostgreSQL** – podatkovna baza
- **Firebase** – REST API / backend
- **WebSockets** – pogovori in ujemanja (matchi)
- **Firebase Cloud Storage** – shranjevanje fotografij
- **FCM (Firebase Cloud Messaging)** – obvestila in komunikacija med uporabniki
